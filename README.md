# Bicimex - Aplicación de Comentarios de Productos 🚴‍♂️💬

[![React](https://img.shields.io/badge/React-18.2.0-blue)](https://reactjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0.2-blue)](https://www.typescriptlang.org/)
[![Vite](https://img.shields.io/badge/Vite-4.4.5-yellow)](https://vitejs.dev/)

Aplicación interactiva para gestión de comentarios y sugerencias sobre productos de ciclismo, desarrollada con React, TypeScript y Vite.

![image](https://github.com/user-attachments/assets/f4e81126-6418-477f-9394-1ddec79e94ab)


## Características principales ✨

- 📝 CRUD completo de solicitudes de comentarios
- 🗂 Filtrado por categorías (UI, UX, Enhancement, etc.)
- 🔍 Ordenamiento por votos/comentarios
- 📊 Vista de Roadmap con columnas de estado
- ✏️ Validación de formularios en tiempo real
- 💬 Sistema de comentarios y respuestas
- 👍 Funcionalidad de votación

## Requisitos del sistema ⚙️

- Node.js 16+
- npm 8+ o yarn 1.22+

## Instalación 🛠️

```bash
git clone https://github.com/miguel807/BicimexFront.git
cd bicimexFront
git checkout master
git pull
npm install
npm run dev
